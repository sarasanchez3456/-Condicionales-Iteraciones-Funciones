# Fundamentos de Python - Control y Funciones

Este repositorio contiene las soluciones a los retos de programación en Python, enfocados en condicionales, funciones y estructuras iterativas.

**Desarrollado en colaboración con:** Juan Pablo Serna Arboleda.

## Requisitos
- Tener instalado Python 3.x.

## Ejercicios

### 1. Reto 1: Funciones (`src/funciones/reto1.py`)
Este script solicita información sobre los proyectos asignados a un programador, incluyendo el número de proyectos y las horas dedicadas a cada uno. Luego, genera un reporte con el total de horas trabajadas, el promedio y el porcentaje por proyecto.

**Cómo ejecutarlo:**
Desde la terminal, navega a la carpeta principal del proyecto y ejecuta:
```bash
python src/funciones/reto1.py
```

### 2. Reto 2: Condicionales (`src/condicionales/reto2.py`)
Este script analiza una lista predefinida que simula el stock de un inventario. Clasifica cada producto como "Agotado", "Crítico" o "Adecuado" dependiendo de su cantidad, y al final genera un resumen con los índices de los productos, valores críticos y el porcentaje de disponibilidad.

**Cómo ejecutarlo:**
Desde la terminal, navega a la carpeta principal del proyecto y ejecuta:
```bash
python src/condicionales/reto2.py
```

### 3. Reto 3: Iterativas (`src/iterativas/reto3.py`)
Este script pide al usuario ingresar una frase o párrafo largo. Limpia el texto eliminando signos de puntuación y pasándolo a minúsculas, luego cuenta la frecuencia de cada palabra usando un diccionario, y determina cuál es la palabra que más se repite en el texto ingresado.

**Cómo ejecutarlo:**
Desde la terminal, navega a la carpeta principal del proyecto y ejecuta:
```bash
python src/iterativas/reto3.py
```
